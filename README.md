# 青绿思享 · 生态文明学习智能体

面向《新时代中国特色社会主义理论与实践》第七章「新时代中国特色社会主义生态文明建设」的课程学习智能体。
纯前端、零依赖、可离线，托管在 GitHub Pages 上，打开链接即可使用。

- 在线地址：https://liuzuning666-pixel.github.io/eco-agent/
- 作者：刘祖宁（第七组 · 生态文明建设）
- 版本：v1.0（2026 年 11 月）

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 课程问答 | 用中文自然语言提问，命中课程知识库并给出「一句话—要点—依据—延伸」的结构化回答 |
| 推理过程可视 | 每次回答展开「理解 → 检索 → 组织 → 自检」四步，能看到命中了哪几条知识 |
| 案例拆解 | 余村、塞罕坝、八步沙、库布其、新安江、秦岭违建等 15 个正反案例，按「地点—时间—做法—成效—启示」呈现 |
| 随堂测验 | 32 道题随机抽 5 题，即时判分与解析，错题进入学习报告 |
| 汇报提纲 | 按课程「典、章、时、评」四环节，输入主题与时长，生成带时间分配的提纲并自动配可引用条目 |
| 政策时间线 | 2005 年余村 → 2026 年《生态环境法典》，23 个节点串起二十年 |
| 学习报告 | 汇总提问、覆盖知识点、测验正确率，可直接贴进作业说明 |
| 可选大模型 | 自带 Key 时可调用 OpenAI 兼容接口润色回答；不填就走本地推理，零成本、不联网、不泄露 |

## 目录结构

```
index.html                 页面骨架（8 个视图）
assets/css/style.css       样式（深绿 + 金，楷体引文，响应式）
assets/js/data/            知识库（71 条）：理论 / 制度 / 目标 / 案例 / 方法 / 辨析、题库、时间线、金句
assets/js/engine.js        中文 bigram 倒排 + BM25 检索、意图识别、回答合成、提纲生成
assets/js/app.js           界面逻辑、本地存储、大模型调用、学习报告
```

## 技术说明

- **检索**：中文按二元组切分建倒排索引，BM25（k1=1.35, b=0.72）打分，标题与标签加权；对问句做「课程范围内」闸门判断，超出范围时明确说明而不硬答。
- **回答合成**：先识别意图（概念 / 原因 / 路径 / 案例 / 方法 / 时间 / 辨析），再按条目类型选择模板（要点式、案例式、正反辨析式），最后附出处与相关条目。
- **无后端**：所有计算在浏览器完成；对话记录、测验成绩存 `localStorage`。
- **可移植**：直接双击 `index.html` 也能用，不需要服务器。
